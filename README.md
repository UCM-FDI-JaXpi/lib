# Libreria - JaXpi

La libreria de JaXpi se integra con juegos desarrollados en JavaScript o TypeScript con propositos de e-Learning, permitiendo la captura de datos del jugador a traves de trazas en formato xAPI para su posterior análisis.

## 1. Guia de instalación
### 1.1. Módulo JaXpi
para instalar el modulo simplemente se puede instalar desde node
`$ npm install jaxpi`
